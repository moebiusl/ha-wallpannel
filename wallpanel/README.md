# HA Wallpanel

Touch-optimiertes Wallpanel fuer Home Assistant.

Dieses Add-on startet die Node/Express-App direkt auf dem Home-Assistant-Server. Innerhalb von Home Assistant nutzt es automatisch die Supervisor-Verbindung zur Home-Assistant-Core-API.

Kamera-URLs, go2rtc, PIN und die wichtigsten Home-Kacheln koennen im Add-on unter "Konfiguration" angepasst werden. Fuer alte iPads sollte `go2rtc_public_url` auf eine LAN-Adresse zeigen, die das iPad direkt erreichen kann.
